lab (`lab_1_1.py`, …), run on the Linux desktop (RTX 4090) from the repo's root uv environment:

    uv run --group cuda python course4/cuda/python/lab_1_1.py

Add the group once on the Linux box: `uv add --group cuda numba cupy-cuda12x`.
